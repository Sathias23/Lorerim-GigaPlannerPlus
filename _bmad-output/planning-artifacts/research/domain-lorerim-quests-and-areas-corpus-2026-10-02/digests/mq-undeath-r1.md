## Contradictions
- Start condition: the mod pages (Undeath and Classical Lichdom) say level 30. The LoreRim install removes the level check and requires two vanilla quests instead. This isn't a true contradiction, because LoreRim layers a patch on top, but an agent quoting the Nexus "level 30" would be wrong for LoreRim.
- Altar requirement: base FAQ says max Enchanting, Classical Lichdom says 50 Ench / 75 Conj (MCM-configurable), and LoreRim's patch says 80/80. The live install wins: 80/80. The MCM can still change it.
- Requiem - Undeath says it "removed spells", yet the Classical Lichdom page lists Lich spells. Requiem - Undeath.esp does override Lich spells (Ice Coffin, True Sight, Summon Diilonthur and others) rather than visibly deleting them. Exactly which spells a LoreRim Lich gets was not resolved.
- Quest name spelling: Undeath.esp has "The Path of Transcendance", while the UndeathFixes override (which wins) has "The Path of Transcendence".
